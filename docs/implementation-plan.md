# 阅见 1.1.0 · 实施与核对

目标：把侧栏简化为直接聊天，自动掌握当前网页已加载的整页文字，保留连续对话和写作工作流。设计依据：[design.md](design.md)。

## 本版实施范围

1. **权限与升级。** 普通 HTTP(S) 网站改为安装或更新时统一接受读取权限。升级采用覆盖原文件夹、保持路径、重新加载并确认 1.1.0 的流程；随后刷新网页并重开侧栏，不卸载旧版。
2. **聊天界面。** 删除来源卡片及其旧操作，改为简短状态、刷新和粘贴图标。保留聊天、历史、设置、快捷提问及持续写作入口。
3. **当前页更新。** 默认在切换标签页和页面加载后读取，侧栏可见时每 5 秒本机刷新；发送附带网页的消息前再次读取。`autoRead` 控制自动更新，`usePageContext` 控制附带网页，两个设置独立。
4. **整页提取。** 覆盖已加载的导航、评论、页脚、屏幕下方文字、开放 Shadow DOM 和同源 iframe。排除隐藏、表单输入及可编辑内容；不做 OCR，不自动滚动或点击，不绕过受保护页面或访问限制。
5. **来源预算与保存。** 单页 120,000 字符；当前页优先，来源合计 240,000 字符。每个会话保留最近 6 份来源快照正文，更早的来源元数据及对话历史保留。历史上下文预算 40,000 字符，会话上限 40 个；存储失败如实报错。
6. **交付说明。** 同步 README、安装页与更新说明，保留源码、设计、测试及验证记录；最终打包版本由主流程核对。

## 核对重点

- 切换标签页后，不能把旧网页误当当前页；读取失败不应静默沿用旧正文。
- 关闭自动读取、保留附带网页时，发送前仍需读取；关闭附带网页不删除已有会话来源。
- 自动读取和刷新只处理本机数据，不自动发起付费 API 请求。
- 同一会话可持续追问和切页比较；最近 6 份正文保留窗口不得变成第 7 个来源的硬性阻挡。
- 页面超长、历史裁剪、存储失败和网络中断都需有准确提示。
- 外部网页内容不能触发权限操作；模型输出不能执行 HTML、脚本或危险链接。
- Chrome 若限制网站访问，应指导用户到「详情 → 网站访问权限 → 在所有网站上」调整。

## 验证与尚待补齐的检查

运行 `npm test`，以 [VALIDATION.md](../VALIDATION.md) 为测试结果、数量及跳过原因的唯一记录。当前环境缺少 Chromium，真实浏览器相关测试会跳过；控制器测试替身不能替代真实扩展加载验证。

交付前核对文档版本、安装包结构和源码一致性。真实 Chrome 中仍需补齐：加载扩展、升级接受权限、360px 窄侧栏布局、切页与动态页面更新、发送前读取、设置和历史保留、粘贴与导出。没有用户 Key，不声称已完成真实付费 API 调用。
