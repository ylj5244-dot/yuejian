# 阅见 1.2.0 · 设计说明

Chrome Manifest V3 侧边栏扩展，支持桌面 Chrome 116+。原生 HTML、CSS 和 JavaScript ES modules，无构建步骤、服务器或内置 API Key。

## 产品流程

打开侧栏后直接讨论当前网页，按需联网核实，再按用户偏好组织回答或写评论。顶部保持紧凑的网页状态、刷新和粘贴入口；输入框保留深度思考，新增默认开启的「联网核实」。历史、新建、设置、复制和 Markdown 导出继续可用。

快捷指令只填入草稿，不自动发送。网页自动读取不调用模型或搜索；只有用户发送或主动重试才进入付费请求流程。

## DeepSeek 官方联网搜索

复用现有 DeepSeek API Key，不要求第三方搜索密钥。`webSearchEnabled` 默认 true，输入框开关修改后存入本机，重启后恢复。

1. 使用当前模型发起一次简短的非流式规划请求，根据当前问题、页面标题、当前附带网页最多 6,000 字符的摘录和相关上一问题拟定 1–2 条搜索词。规划失败时可退回本机组合关键词，不把关键词规划当成搜索结果。
2. 调用 `https://api.deepseek.com/v1/tools/search`，最多 2 次；每次请求 `count: 5`、`need_content: true`。搜索请求携带最多 128 个 Unicode 字符的搜索词和原问题，网页摘录只用于同属 DeepSeek 的规划请求。
3. 整理真实返回的正文或摘要，将材料与其 URL、检索词、时间、所属轮次和覆盖范围一并传给回答模型。只能引用实际返回的来源网址，不能虚构访问过程或把摘要当全文。
4. 展示可展开的联网来源，供用户查看检索词、时间和 URL。历史搜索仍属于原来的时间和轮次，不能冒称本轮最新检索。

搜索请求失败则本轮不继续生成回答，显示失败原因；支持停止、手动重试或关闭联网后再次提问。没有可用结果时说明资料不足，不编造检索证据。停止应取消规划、搜索或回答中正在进行的请求，且不把中断标成成功。

费用由用户账户承担：规划是一次按 token 计费的模型请求，搜索按 DeepSeek 官方规则另行计费，最终回答按模型用量计费。不把本机网页读取描述为联网搜索，也不因自动读取而发起付费请求。尚未完成真实计费接口验证，不能把模拟测试称为线上付费调用成功。

## 长期偏好与快捷指令

三项独立偏好通过本机扩展存储持久化：`style` 为写作风格，`replyStyle` 为日常回答偏好，`memory` 为用户手动填写的长期背景与要求。保存后，所有新旧会话的后续请求都采用当前偏好，不改写已经生成的历史回复。重启恢复；不训练模型，不自动提炼或记住所有聊天，不跨设备同步。

快捷指令存为有序列表，最多 8 条，每条名称最多 24 字符、指令最多 4,000 字符。支持编辑、新增、删除、上下移动、恢复默认和空列表；必须保留用户明确保存的空列表，不能重启后强行恢复默认。保存后欢迎页和底部入口同步更新，既有会话也使用新配置。点击只填入草稿。

迁移旧设置时保留 API Key、原有 `style` 和历史对话，为新增字段补默认值。联网开关和快捷设置重启后保持。卸载或清除扩展数据会丢失本机内容。

## 权限与当前页读取

普通 HTTP(S) 网站读取权限在安装或更新需要时统一接受。`tabs` 用于当前标签页标题和地址，`scripting` 用于当前页提取；不调用浏览历史接口，不遍历全部标签页，不读取 Cookie。若 Chrome 限制访问，引导到扩展「详情 → 网站访问权限 → 在所有网站上」。

`autoRead` 默认开启：侧栏可见时，在标签页切换、页面加载后读取，并每 5 秒在本机刷新。关闭侧栏或此开关后停止自动更新。`usePageContext` 独立控制发送时附带当前页，默认开启；发送前会重新读取，即使 `autoRead` 已关闭。自动重读不得抢占发送前的读取。

提取已加载并显示的整页文字，包括导航、评论、页脚、屏幕下方内容、开放 Shadow DOM 和可访问的同源 iframe。保留固定定位、全屏布局兼容、iframe 异常隔离、主脚本结构化错误及自动可见文字兼容读取。兼容或已知不完整的结果标记 `partial`，界面显示「部分内容」，不能宣称全文。

排除隐藏、表单输入和可编辑内容。不做截图、OCR、音视频识别，不支持跨域 iframe、受保护页面或 PDF；不自动滚动、点击、展开，不绕过登录或付费墙。未加载内容不能取得。当前页失败不得静默沿用旧页正文；可用粘贴补充。

设置保留「读取诊断」与复制入口，只包含站点域名、读取状态和错误代码，不含正文、对话或密钥。

## 来源预算与存储

- 网页单页上限 120,000 字符；发送时当前页优先，网页来源合计不超过 240,000 字符。
- 每个会话保留最近 6 份网页快照正文；更早正文清空，来源元数据和聊天历史保留。这不是可讨论网页数量上限。
- 搜索结果单轮正文上限 40,000 字符；保留最近 3 轮搜索结果正文。构造回答请求时，搜索材料使用独立的 60,000 字符总预算，不挤占网页来源预算。更早正文释放后仍保留检索词、时间、来源 URL 和状态。
- 历史聊天预算 40,000 字符，裁剪时提示；不把模型思考过程或空白、失败的助手消息当作正常历史发送。
- 最多 40 个会话，达到上限时提示用户导出或删除不需要的会话。存储失败明确报错，不宣称已保存。
- Key、偏好、开关、快捷指令和历史仅保存在本机扩展存储，Key 未加密。关闭侧栏取消当前请求，已保存的部分回复可恢复查看。仅允许一个 Chrome 窗口同时使用侧栏，避免存储覆盖。

## 模型与安全边界

规划和回答连接 DeepSeek 官方对话 API，搜索连接其官方 `/v1/tools/search`，无第三方中转或遥测。默认 `deepseek-flash`，支持 `deepseek-v4-pro`、自定义模型 ID 和深度思考；规划使用短请求并关闭深度思考。

网页和搜索材料均是不可信资料，只供分析，不能修改偏好、长期记忆、权限或触发网页操作。模型只能依据明确提供的检索材料说明搜索所得。Markdown 安全渲染，不执行原始 HTML、脚本或远程图片。

## 模块分工

- `background.js`：工具栏点击与侧栏打开。
- `panel.html` / `panel.css`：聊天、联网开关、偏好与快捷编辑、来源详情、诊断界面。
- `panel.js`：当前页状态、读取、搜索及回答流程、会话持久化、停止与重试。
- `lib/extract.js` / `lib/fallback.js`：主提取、兼容可见文字提取及范围标记。
- `lib/search.js`：关键词规划、官方搜索、结果规范化、取消与错误处理。
- `lib/preferences.js`：设置默认值、旧版迁移、偏好与快捷指令校验。
- `lib/context.js`：当前偏好、网页与搜索来源预算、历史组织、Markdown 导出。
- `lib/api.js`：模型请求、SSE 增量解析、取消与错误处理。
- `lib/markdown.js`：安全 Markdown 渲染。

## 交付与验证

升级沿用同一扩展目录，覆盖文件后在 `chrome://extensions` 重新加载并确认 1.2.0；刷新网页再重开侧栏，不建议卸载，以保留原密钥、写作风格和历史。

验证范围包括规划与搜索请求、返回材料、费用触发边界、失败和取消、偏好迁移与持久化、快捷指令、来源预算及既有读取流程。实际通过数、跳过项和验证证据统一记录在 [VALIDATION.md](../VALIDATION.md)。没有真实计费调用就不能声称官方搜索或模型已在用户账户上验证；模拟接口或公开网页只读检查也不能替代扩展安装、登录会话及真实布局验证。
