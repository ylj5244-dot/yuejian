# 阅见 · DeepSeek 阅读与写作

**1.2.0** · Chrome 桌面侧边栏扩展。自动读取当前网页，联网查证相关信息，与 DeepSeek 连续讨论，再按自己的风格写评论。

## 从旧版更新到 1.2.0

1. 关闭阅见侧栏，解压本次 ZIP。
2. 将新 `deepseek-reader` 文件夹中的文件覆盖到**原来加载的同一个扩展文件夹**，保留原路径。
3. 打开 `chrome://extensions`，点击阅见卡片上的重新加载，确认版本为 **1.2.0**。如 Chrome 提示权限或重新启用，请确认。
4. 刷新要讨论的网页，再重新打开阅见侧栏。

**不要卸载旧扩展。** 沿用原扩展和原路径，可保留原有 API Key、写作风格与历史对话。卸载或清除扩展数据会丢失本机内容。

普通 HTTP(S) 网站读取权限在安装或更新需要时统一接受。若 Chrome 仍限制访问，进入阅见的「详情 → 网站访问权限」，选择「在所有网站上」。

## 安装（Mac / Windows）

1. 解压 ZIP，将 `deepseek-reader` 文件夹放在以后不会删除的位置。
2. 使用电脑上的 Chrome 116 或更新版本，打开 `chrome://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择直接包含 `manifest.json` 的文件夹，接受所需权限。
4. 在工具栏拼图菜单中固定阅见。打开普通网页，点击阅见图标。
5. 在设置中填写 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 的 API Key 并保存。联网搜索复用这把密钥，**不需要第三方搜索 Key**。

API 独立计费，需要 API 账户有可用余额。安装不需要 npm 或服务器；iPhone / iPad 上的 Chrome 不支持这种桌面扩展。本扩展未上架 Chrome 商店，使用开发者模式安装。

## 联网核实

输入框下方的「联网核实」默认开启，可以随时关闭；你的选择会保存在本机，重启后仍有效。

发送时，阅见先请 DeepSeek 拟定 1–2 条搜索词，再调用 DeepSeek 官方搜索服务，最多执行 2 次搜索，每次请求 5 条结果及可用正文。随后根据返回的正文或摘要组织回答，并引用结果中的真实网址。展开消息中的「联网来源」，可以查看搜索词、检索时间与来源链接；摘要或部分内容不会被当作已读全文。

**联网核实有额外费用：** 搜索规划是一次较短的模型请求，按 token 计费；搜索服务按 DeepSeek 官方规则另行计费，最终回答也按模型用量计费。本版未完成真实计费调用验证，具体价格和账户可用性以开放平台为准。

搜索过程中可以停止。搜索请求失败时，本轮不会继续生成回答；可手动重试，或关闭「联网核实」后再问。未找到可用结果时，会说明资料不足，不会虚构已找到证据。打开网页、自动读取或点击快捷指令都不会自动调用付费服务。

## 长期偏好与快捷指令

设置中可分别保存：

- **我的写作风格**：写文章或评论时的语气、结构和表达方式。
- **日常回答偏好**：平时讨论问题时，希望怎样回答。
- **长期记忆**：手动填写希望持续参考的背景、关注点或约定。

保存后，所有新旧会话的后续回复都会使用这些内容，重启后保留。它们只存在本机，不跨设备同步，不训练模型，也不会自动记住所有聊天；可随时修改或清空。

「快捷指令」最多 8 条，每条名称最多 24 字符，完整指令最多 4,000 字符。支持编辑、新增、删除、上下排序和恢复默认，也可以全部删空。点击「保存设置」后，欢迎页和底部快捷入口同步更新，新旧会话都可使用，重启后保留。点击快捷指令只填入草稿，你可调整后再发送。

## 直接讨论当前页

- 顶部只保留网页状态、刷新和粘贴图标。直接提问，或点击快捷指令；Enter 发送，Shift + Enter 换行。
- 默认在切换标签页、页面加载后读取；侧栏可见时，每 5 秒在本机更新一次。发送附带网页的消息前，还会重新读取当前页。
- 「自动读取当前网页」控制本机自动更新；「聊天时附带当前网页内容」控制发送时加入当前页。关闭前者、保留后者时，发送前仍会读取。关闭附带网页不会删除已有会话来源。
- 同一会话可持续追问、切页比较或写评论。新话题可点击加号新建对话。支持深度思考、流式回答、停止、手动重试、复制、Markdown 导出和本机历史。

## 网页读取与诊断

尝试读取普通 HTTP(S) 网页中已经加载并显示的整页文字，包括导航、评论、页脚、屏幕下方内容、开放 Shadow DOM 和同源内嵌页面。保留固定定位与全屏布局兼容、iframe 异常隔离，以及自动兼容读取；页面自动更新不会抢占发送前的读取。

不做截图或图片文字识别，不读取隐藏、表单输入及可编辑内容；不支持跨域内嵌页面、受保护页面或 PDF。不自动滚动、展开或点击，也不绕过登录或付费墙。未加载的内容不会被取得。顶部显示「部分内容」时，不能视为完整文章，必要时手动粘贴补充。

仍读不到时，确认已按原路径更新并重新加载 **1.2.0**，刷新网页后重开侧栏，检查网站访问权限，再点顶部刷新图标。若仍失败，打开 **设置 → 读取诊断 → 复制读取诊断**，将结果用于排查。诊断只含站点域名、读取状态和错误代码，不含正文、对话或 API Key。不要卸载扩展排查，以免丢失历史。

## 数据与容量

- 密钥、偏好、快捷指令、联网开关和对话保存在本机 Chrome 扩展存储中，不使用 Chrome 同步。密钥未加密，请勿在共用设备上长期保存。
- 只有发送或主动重试才会请求 DeepSeek。联网时，当前问题、页面标题、当前附带网页的有限文字摘录及相关上一问题会用于规划搜索词；搜索服务接收搜索词和原问题；生成回答时，会提交相关页面、搜索材料、历史和长期偏好。直接连接 DeepSeek 官方服务，没有额外中转或遥测。
- 每页最多 **120,000 字符**，请求中的网页来源合计最多 **240,000 字符**，当前页优先。每个会话保留最近 **6 份网页快照正文**和最近 **3 轮搜索结果正文**；更早的原始正文会清空，但来源信息、搜索词、来源网址和聊天历史保留。
- 搜索材料使用独立预算：单轮最多 **40,000 字符**，一次回答中合计最多 **60,000 字符**。旧聊天上下文预算 **40,000 字符**；超限会裁剪并提示。
- 最多保留 **40 个会话**，达到上限后请先导出或删除不再需要的会话。保存失败会明确提示，不会假装已保存。
- 扩展不调用浏览历史接口、不遍历全部标签页、不读取 Cookie。关闭侧栏停止自动读取并中断当前请求；已保存的部分回复仍可查看。为避免存储互相覆盖，同一时间仅在一个 Chrome 窗口中使用阅见。

## 开发与验证

原生 JavaScript、HTML 和 CSS，无构建步骤。开发者可运行 `npm test`；真实浏览器测试需要 Playwright 与 Chromium，安装使用不需要这些依赖。搜索使用 `https://api.deepseek.com/v1/tools/search`，规划和回答使用 DeepSeek 对话 API。

设计见 `design.md`，测试结果和验证边界以 [VALIDATION.md](../VALIDATION.md) 为准。未完成真实计费搜索或模型调用验证；模拟接口测试、公开网页只读检查不代表已验证用户的扩展安装、登录会话或完整文章。

官方参考：[Chrome Side Panel](https://developer.chrome.com/docs/extensions/reference/api/sidePanel)、[DeepSeek API](https://api-docs.deepseek.com/)。本扩展与 DeepSeek 或 OpenAI 无官方隶属关系。
