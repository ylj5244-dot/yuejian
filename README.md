# 📖 阅见

Chrome 里的网页阅读与 AI 讨论助手。边看网页边聊，让 DeepSeek 梳理内容、查找依据，再按你的风格写评论。

## ⬇️ 下载与安装

[📦 下载 Chrome 安装包](https://github.com/ylj5244-dot/yuejian/releases/download/v1.2.0/yuejian-1.2.0-chrome.zip) · [📋 全部下载与说明](https://github.com/ylj5244-dot/yuejian/releases/latest)

当前版本 **1.2.0**，适用 Mac / Windows 桌面版 **Chrome 116 及以上**。解压后，在 `chrome://extensions` 开启「开发者模式」，点击「加载已解压的扩展程序」，选择包内的 `deepseek-reader` 文件夹。无需搭服务器，也无需安装开发工具。

本扩展尚未上架 Chrome 应用商店；iPhone / iPad 上的 Chrome 不支持这种桌面扩展。

## ✨ 能做什么

- 📄 **直接讨论网页**：打开侧边栏后自动提取当前页面已加载的文字，发送前再更新一次；切换网页后可以在同一对话中比较和追问。
- 💬 **连续聊天与写作**：支持流式回复、深度思考、停止、重试、复制和 Markdown 导出；原文、搜索来源和讨论记录保存在会话中。
- 🌐 **联网核实**：可选 DeepSeek 官方搜索，先检索再回答，保留可点击的来源，并区分搜索摘要和取得的正文。
- ✍️ **记住你的偏好**：分别设置写作风格、日常回答方式和长期要求；保存后，新建对话、重启浏览器都继续生效。
- ⚡ **自定义快捷提问**：修改按钮名称与完整提示词，支持增删和排序，最多 8 条。点击填入草稿，确认后再发送。

## 🚀 三步开始

1. 下载、解压并在 Chrome 扩展管理页加载 `deepseek-reader`。
2. 打开普通网页，点击工具栏的「阅见」，在设置中填写自己的 [DeepSeek API Key](https://platform.deepseek.com/api_keys)。
3. 直接输入问题，或点击快捷提问；需要写评论时，先在设置里保存你的写作偏好。

AI 与搜索调用由 DeepSeek 按用量计费。联网核实默认开启，可以在输入框下方关闭。自动读取网页和点击快捷提问不会发起付费调用。

## 🔄 从旧版升级

关闭侧栏，用新版文件覆盖**原来加载的同一个文件夹**，在 `chrome://extensions` 点击「重新加载」，确认版本 **1.2.0**，再刷新网页并打开侧栏。**不要卸载旧扩展或改变原路径**，以便保留 API Key、偏好和历史。

## 💾 数据与读取范围

API Key、偏好、快捷提问和聊天记录保存在本机 Chrome 扩展存储，不跨设备同步。Key 未加密，请勿在共用设备上长期保存。发送问题或主动重试时，相关网页、对话和偏好会提交给 DeepSeek；联网时还会请求搜索服务。没有额外中转或遥测。

读取的是**当前页面已经加载并显示的文字**，每页最多 12 万字符；图片文字、PDF、尚未加载内容和部分内嵌页面不支持。不绕过登录或付费墙，显示「部分内容」时不能视为全文。长期记忆由你手动填写，不会自动记住所有聊天。
